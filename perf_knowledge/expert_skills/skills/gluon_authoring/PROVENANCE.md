# PROVENANCE - what this tree is built from and what was removed

Maintainer note; agents do not need it. `facts.jsonl`, `INDEX.md`, `skill.md` (body), `scripts/q.py` and
`scripts/lint_facts.py` are generated from one card source by the skill's build script (outside this
tree); `INDEX.md` is regenerated by `scripts/lint_facts.py --write-index` and checked by
`scripts/lint_facts.py`. Edit the source cards, not the generated files.

Origin: the upstream `tile-programming-gluon` pack (AMD-AGI/TileProgrammingAgentSkills@a649eaaf),
reorganized gfx950-first, extracted from a larger agent framework, then cleaned into fact cards.
Tools (`scripts/` here and `kernel_workflow/scripts/kernel_tools/`) are unchanged except for pointers to
removed docs; tests that asserted removed prose were updated or removed (see the commit message).

## Removed, and why

| removed | why |
| --- | --- |
| `references/playbook.md`, `references/reference.md` | lever menu and lookup index: prescriptive priority orders and a pointer index; the facts they held are cards, the lookup is `q.py` + `INDEX.md` |
| `references/gluon/**` (27 pages) | Gluon API, layout, memory, pipeline and inline-asm facts moved to cards (`api`, `layout`, `mfma`, `async`, `lds`, `pipe`, `asm` groups); router stubs, method prose and duplicated tables dropped |
| `references/tile-programming/**` (13 pages) | compiler contract, llvm_fn_attrs, warp pipeline, low precision, memory path: facts moved to cards (`compiler`, `attrs`, `wpipe`, `lowp`, `mem`); mental-model and scheduling-model essays dropped as general knowledge |
| `references/hardware/**` (12 pages) | ISA, LDS, occupancy, SKU and profiler-counter facts moved to cards (`isa`, `lds`, `occ`, `hw`, `sku`, `prof`); textbook roofline, duplicated arch tables and priority "laws" dropped; numbers stay in `data/` |
| `references/workloads/**` (12 pages) | per-kernel-class design notes (GEMM, attention, MoE, linear attention, collectives) deleted entirely; only compiler/ISA/runtime mechanisms found there survive as cards |
| `references/method/**`, `references/pitfalls/negative-patterns.md` (`references/pitfalls/platform-known-issues.md` is KEPT: default-path GEAK pages `perf_knowledge/hardware/rdna*` and two node tests link it; nothing in this skill routes to it) | workflow/round process and pitfall lists: tool behaviour became `kind: tool` cards, pitfalls became `error`/`trap` cards; process prose dropped |
| `scripts/{USAGE,README}.md`, `kernel_workflow/scripts/kernel_tools/{CARD,README,isa_tools,profiling-dependencies}.md` | prose tool docs replaced by `kind: tool` cards (`q.py --kind tool`); each tool's `--help` is the detailed doc |
| `scripts/{check_pack_refs.py,check_pack_refs.allow,gen_section_map.py,check_term_index.py}` and their tests | checkers/tests of the removed prose (link resolution, section map, term index, CARD.md); `scripts/lint_facts.py` checks the cards |
| `playbook.md` front matter / `playbook_file` | the injected entry is `skill.md`; the reference has no playbook |
| all experiment records | benchmark-task names, task shapes and tiles, run timings, speedups, dates and run provenance were removed from every card (lint-checked); a performance statement survives only as a mechanism with its condition and a `check` |

`overrides[]` on a card replaces the former inline **Overrides KB** notes: the named GEAK knowledge file is
superseded for that card's scope.
