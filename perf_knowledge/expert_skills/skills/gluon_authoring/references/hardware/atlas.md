# Hardware atlas — entry point

**Read this first** for AMD hardware on gfx950 / gfx942 (and RDNA downgrade). Deep docs
are split by **question**; this file routes by **optimization phase** and **backbone
layer**. DSL API: `../gluon/index.md`. Tile-op card axes: `../tile-programming/tile-op-contract.md`.

## Two layers — ISA vs SKU

| Layer | Files | Use for |
| --- | --- | --- |
| **ISA / microarch** | `capability-matrix.md`, `planning-constants.md`, `isa-mechanisms.md` | Lever gate, LDS/VGPR/occupancy, MFMA shapes — **per gfx_\*** |
| **SKU planning peaks** | `amd-cdna4-skus.md` (gfx950, main line), `amd-cdna3-skus.md` (gfx942 downgrade), `amd-rdna4-skus.md`, `amd-rdna35-skus.md`, `amd-rdna3-skus.md` — all rendered from `perf_knowledge/hardware/data/sku.json` | Roofline ridge, `t_ideal`, saturation (`CUs`), layer-6 L2 locality (`L2_MB`) |

Same ISA can ship on different SKUs with different peaks (MI355X vs MI350X: both gfx950, 2.5 vs 2.3
PF FP16; MI300X vs MI325X vs MI308X: all gfx942; RX 9070 XT (gfx1200) vs AI PRO R9700 (gfx1201):
RDNA4 client WMMA). **gfx1250 (CDNA5 / MI450) is a separate data-center ISA,
not RDNA4** — do not mix. **Budget phase:** pick the SKU row first, then read microarch constants for that `isa_class`.

`scripts/calc_perf.py --sku <key>` (a shim to `kernel_workflow/scripts/kernel_tools/calc_perf.py`; same
for `hw_budget.py`, `mem_bw_probe.py`, `extract_sku.py`) — **pick the chip on the box**
(`scripts/gpu_identity.py` → `sku`). Omitting `--sku` is **refused**: no tool assumes a SKU,
and a dtype the row does not list is refused rather than priced at FP16.

## Table A — Phase read order

| Phase | Read | Output |
| --- | --- | --- |
| Budget (no profile yet) | `roofline-models.md` → **SKU file for chip** → `planning-constants.md` | `t_ideal`, ridge, saturation, preliminary bound class |
| Profile | `../method/profile.md` + `bound-class-signals.md`; IR: `scripts/dump_ir.sh` → `scripts/asm_loop_audit.py` | Confirmed bound class |
| Lever gate | `capability-matrix.md` §Bound class → lever + Layer row | ✓ / ◐ / blocked |
| Layer loop round N | **Table B** row N → DSL file | One tile-op card cell change |
| Recalibrate | `roofline-models.md` §Calibration | Updated Layer Ledger constants |
