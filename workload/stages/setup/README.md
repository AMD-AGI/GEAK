# Setup

Prepare the runtime and resources required by the plan under the
[invocation contract](../CONTRACT.md#direct-module-calls).

**Input:** task/scenario, requested runtime, resource permissions and existing handles.
**Output:** usable runtime/resource identities, preparation evidence and any blockers.
**Acceptance:** the required tools and resources are usable within the granted scope.
Preparation does not establish a measured baseline.
