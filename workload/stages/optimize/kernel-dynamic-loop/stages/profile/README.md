# Profile

Resolve a bottleneck question under the [shared contract](../CONTRACT.md).
Initial implementation: [native-profile](native-profile/SKILL.md).

**Input:** a question, exact source/input identity and prior observations.
**Output:** evidence, coverage, uncertainty and a discriminating next experiment.
**Acceptance:** conclusions identify their source and coverage; estimates and reused
observations are distinguished from new measurements. Unknowns remain explicit.
