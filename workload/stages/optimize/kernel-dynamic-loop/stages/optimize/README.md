# Optimize

Produce an isolated candidate under the [shared contract](../CONTRACT.md).
Initial implementation: [native-coding](native-coding/SKILL.md).

**Input:** a hypothesis, verified starting source, editable boundary and direction budget.
**Output:** candidate source identity, changes, costs and screening evidence for Verify.
**Acceptance:** the candidate stays within the declared boundary and is reproducible.
A successful compile or one fast case does not establish a full-task improvement.
