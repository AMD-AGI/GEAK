# Native coding

Read the [Optimize contract](../README.md).
Copy the complete computation source into this call's directory and edit only declared
leaves. Choose tools for the hypothesis: algorithm, layout, scheduling, code generation
or host launch work. A different backend is another candidate when existing bindings allow it.

Independent directions may use parallel coding agents when available, each with its own
copy and budget. They do not concurrently edit or test the canonical task. Retain small
diagnostic probes as screening evidence, then hand the candidate to Verify.
