# Local evidence note

Read the [Learn contract](../README.md).
Record the useful constraint, failed hypothesis or successful mechanism and its scope
in the local handoff or a linked note. Update existing notes rather than creating a
memory file every round. An interrupted attempt does not refute its hypothesis.

Return the lesson and its evidence pointers. Draft portable lessons locally; unverified
candidates are not promoted into shared knowledge.
