# Learn

Retain a useful lesson under the [shared contract](../CONTRACT.md).
Initial implementation: [local-note](local-note/SKILL.md).

**Input:** a finding that could change a later decision, with supporting evidence.
**Output:** a concise local lesson, applicability limits and unresolved questions.
**Acceptance:** the lesson separates verified facts from hypotheses and distinguishes
implementation failures from invalid or interrupted measurements. Shared publication
follows the destination's existing validation and authorization policy.
