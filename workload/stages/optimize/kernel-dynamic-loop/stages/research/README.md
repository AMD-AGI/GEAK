# Research

Find applicable evidence or approaches under the [shared contract](../CONTRACT.md).
Initial implementation: [evidence-search](evidence-search/SKILL.md).

**Input:** an unresolved question, current evidence, task/hardware constraints and permitted sources.
**Output:** a candidate or testable hypotheses with references and applicability limits.
**Acceptance:** useful claims retain their source/version, assumptions and the current
evidence needed to qualify them. Borrowed code still requires Verify; published speedups
are not measurements of this task.
