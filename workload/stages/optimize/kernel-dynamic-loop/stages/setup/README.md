# Setup / Benchmark

Establish usable task and measurement inputs under the [shared contract](../CONTRACT.md).
Initial implementation: [task-inspect](task-inspect/SKILL.md).

**Input:** the question, supplied task, source identity, prior receipts and assigned resources.
**Output:** usable input/measurement evidence and observed test cost, or a specific blocker.
**Acceptance:** evidence matches the computation, source bindings and device width;
required native baseline refreshes have occurred. Readiness is not a performance result.
