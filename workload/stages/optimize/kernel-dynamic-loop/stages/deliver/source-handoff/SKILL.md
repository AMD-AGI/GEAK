# Source handoff

Read the [Deliver contract](../README.md).
Finish active calls and preserve their output. Place the verified inner incumbent's
declared edits in the canonical task. If time ends before full verification, a promising
candidate may instead be submitted explicitly as pending for the worker's native sweep.

Write `RUN_DIR/HANDOFF.md` with selected source identity and verification status, call
report links, rejected/unfinished directions, costs, blockers and the next useful plan.
The worker's subsequent receipt overrides earlier claims. Hand control back without
marking its campaign complete or repeating a worker-owned sweep.

For a requested route review, reuse the existing
[HTML report module](../../../../../report/html-timeline/SKILL.md).
