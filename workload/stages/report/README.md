# Report

Explain the campaign's actual decisions and module calls under the
[invocation contract](../CONTRACT.md#direct-module-calls).

**Input:** brief/state, invocation plans/reports, native results and timestamps.
**Output:** a readable route summary linked to evidence, including concurrency and repairs.
**Acceptance:** it preserves the actual order, outcomes and known timing limits.
Reporting presents evidence; it does not rerun evaluation or change a verdict.

Implementation: [HTML timeline](html-timeline/SKILL.md), with an
[interactive example](html-timeline/assets/example.html).
